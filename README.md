# 💣 Crazy Arcade - C++ & SFML

C++과 SFML을 활용하여 제작한 **크레이지 아케이드 스타일의 로컬 2인 대전 게임**입니다.

한 PC에서 두 명의 플레이어가 각자의 캐릭터를 조작하여 물풍선을 설치하고,
블록을 파괴해 아이템을 획득하며 상대 플레이어를 공격하는 방식으로 진행됩니다.

각 기능을 역할별로 나누어 개발한 뒤 Git/GitHub를 이용해 `main` 브랜치에 통합했습니다.

## 🎮 게임 소개

두 명의 플레이어가 하나의 키보드를 이용하여 대전하는 게임입니다.

플레이어는 맵을 이동하면서 물풍선을 설치할 수 있으며,
일정 시간이 지나면 물풍선이 십자 방향으로 폭발합니다.

폭발을 이용해 파괴 가능한 블록을 제거할 수 있으며,
블록이 파괴되면 일정 확률로 아이템이 생성됩니다.

아이템을 획득하면 물풍선 설치 개수, 폭발 범위, 이동 속도 등의 능력치를 강화할 수 있습니다.

상대 플레이어가 물풍선 폭발에 맞으면 갇힌 상태가 되며,
일정 시간 안에 탈출하지 못하면 패배합니다.

## 🕹️ 조작 방법

### 게임 플레이

| 기능 | 1P | 2P |
|---|---|---|
| 위 | `W` | `↑` |
| 아래 | `S` | `↓` |
| 왼쪽 | `A` | `←` |
| 오른쪽 | `D` | `→` |
| 물풍선 설치 | `SPACE` | `ENTER` |
| 바늘 사용 | `F` | `RSHIFT` |

### 캐릭터 선택

| 기능 | 1P | 2P |
|---|---|---|
| 캐릭터 변경 | `A` / `D` | `←` / `→` |
| 선택 완료 | `SPACE` | `ENTER` |
| 선택 취소 | `Q` | `RSHIFT` |

두 플레이어가 모두 캐릭터 선택을 완료하면 게임이 시작됩니다.

| Branch | 역할 |

## 🤝 기능 통합 방식

각 기능은 독립적으로 구현하되,
`Game`에서 필요한 기능을 연결하는 방식으로 통합했습니다.

예를 들어 플레이어 이동 시에는 다음 요소가 함께 동작합니다.

```text
Player
  │
  ├── TileMap
  │     └── 이동 가능한 위치인지 확인
  │
  ├── WaterBalloonSystem
  │     └── 이동하려는 위치에 물풍선이 있는지 확인
  │
  └── Player
        └── 상대 플레이어와 충돌하는지 확인
```

물풍선이 폭발하면 다음 기능들이 연결됩니다.

```text
WaterBalloonSystem
  │
  ├── TileMap
  │     └── 파괴 가능한 블록 제거
  │
  ├── ItemManager
  │     └── 블록 파괴 위치에 일정 확률로 아이템 생성
  │
  └── Player
        └── 폭발 범위에 들어온 플레이어 피격 처리
```

아이템을 획득하면 플레이어의 능력치와 물풍선 시스템에 효과가 적용됩니다.

```text
ItemManager
     │
     ▼
 ItemStats
     │
     ├── 물풍선 설치 개수
     ├── 폭발 범위
     ├── 이동 속도
     └── 바늘 개수
```
