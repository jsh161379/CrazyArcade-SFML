Optional PNG replacements
=========================
grass.png, road.png, road_line.png, crosswalk.png
house_red.png, house_blue.png, house_yellow.png
tree.png, bush.png, crate.png, brick_red.png, brick_orange.png

Ground: square, fills one tile.
Objects: transparent background, one tile wide, bottom-aligned, aspect preserved.
Missing files use code-drawn art. Restart the application after changing images.
Build copies this directory beside the executable.
See ../README.md for Korean setup and map-editing instructions.
